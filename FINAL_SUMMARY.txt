NEW FEATURES
================================================================================

1. AUTOMATIC SNAPSHOTS
   - Captures combatant state at the start of each round
   - Tracks: HP, position (x/y coordinates), conditions, NPC/PC status
   - Lightweight in-memory storage

2. CHANGE AUTO-DETECTION
   - Damage taken: "Goblin took 15 damage (30 → 15 HP)"
   - Healing: "Fighter healed 8 HP (12 → 20 HP)"
   - Movement: "Wizard moved approximately 30 ft"
   - Conditions gained: "Rogue gained condition: Poisoned"
   - Conditions lost: "Barbarian lost condition: Stunned"
   - Combatants joining/leaving combat

3. GM DESCRIPTION DIALOG
   - Appears at the start of each round (after round 1)
   - Shows auto-detected changes in highlighted section
   - Pre-fills text area with detected changes
   - GM can add narrative details
   - Save or Skip options
   - Clean, themed UI

4. COMBAT HISTORY IN AI PROMPTS
   - Automatically includes recent round descriptions
   - Configurable context window (1-10 rounds, default: 3)
   - Provides tactical context to AI for better decisions
   - Formatted clearly for LLM consumption

5. CONFIGURATION SETTINGS
   - Enable/Disable Round Tracking (default: ON)
   - Round History Context: Number of rounds to include (default: 3)
   - Accessible via standard Foundry settings

HOW TO USE
================================================================================

FOR GMs:
1. Enable the module in your world
2. Configure LLM settings (if not already done)
3. Verify "Enable Round Tracking" is ON in settings
4. Start a combat encounter
5. When Round 2 begins, a dialog will appear showing auto-detected changes
6. Add your own narrative description of what happened
7. Click "Save Description" to store it
8. The AI will automatically use this history when making recommendations

FOR DEVELOPERS:
1. Check out the releases/v0.1.0_RoundTracking branch
2. Review IMPLEMENTATION_SUMMARY.md for technical details
3. Follow TESTING_GUIDE.md for testing procedures
4. See ROUND_TRACKING.md for feature documentation
